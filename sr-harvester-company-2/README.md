SR Harvester Company
====================

Simple Spring Boot + Thymeleaf web app (WAR) to calculate and save Harvester bills locally using H2 file DB.

Build:
    mvn clean package

Output:
    target/sr-harvester-company.war -> deploy to Tomcat webapps/

Run (dev):
    mvn spring-boot:run

Access:
    http://localhost:8080/sr-harvester-company/
